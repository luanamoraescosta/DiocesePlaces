# Diocese Assignment Analysis

Analysis of the assignment of historical places to dioceses, comparing two different sources of medieval diocese boundaries: **Germania Sacra** and **Stanford**.

**Author:** Luana Moraes Costa
**Report:** https://luanamoraescosta.github.io/DiocesePlaces/

## About

This project compares historical diocese boundaries and examines how places from GeoNames are assigned to dioceses.

The analysis uses two main sources:

1. **Germania Sacra** — diocese boundaries focused on the historical German area.
2. **Stanford** — historical diocese boundaries for Europe around 1450.

When the two sources disagree, **Germania Sacra is treated as the authoritative source** for this analysis.

## Objectives

* Compare diocese boundaries from Germania Sacra and Stanford.
* Assign GeoNames places to historical dioceses.
* Identify discrepancies between the two boundary sources.
* Visualize the results geographically.
* Produce datasets with clear source attribution.

## Data Sources

| Source             | Description                                        |
| ------------------ | -------------------------------------------------- |
| **GeoNames**       | Processed places with feature class `P`            |
| **Germania Sacra** | Historical diocese boundaries                      |
| **Stanford**       | Historical diocese boundaries for Europe, ca. 1450 |
| **Monasteries**    | Monastery data from Germania Sacra                 |
